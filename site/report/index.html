If a child is in immediate danger, or there is a risk to life

Contact the police on 999, or 101 if it is not an emergency.

Child sexual abuse material

Do not describe the material in detail, attach it, or send it to anybody else. Report it directly to:

  • The National Crime Agency, through CEOP.
  • The Internet Watch Foundation, at report.iwf.org.uk.

Who can act on it

ForgeSworn publishes KithMoot as software. We do not run the relays, file servers or call relays that carry rooms. Nothing we still hold is reachable from outside: the encrypted files left from our closed file store wait to be deleted (privacy notice, section 4.4). Rooms are end-to-end encrypted, so nobody outside a room can read it. The people who can act are those who run the parts involved:

  • A relay can stop storing and serving events. A room's link shows which relays it uses; each relay's operator decides what it carries.
  • A file server can remove a file. Files sent from the web app and the desktop app go by default to blossom.yakihonne.com, run by Yakihonne LLC; report a file to that server's operator.
  • A room's keeper or hosts, where a room has them, can remove members or close the room.
  • The app itself lets you leave a room, and decline and block a person, on your own device.

What we ran until 22 October 2026, and what closed, is in the closure record. How reports were handled while it ran is kept in the archived report-handling runbook.

Something else

For a bug in the app rather than a safety concern, report an issue on GitHub instead.
