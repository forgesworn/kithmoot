1. About these terms

KithMoot is open-source software: a web app, desktop apps and an Android app for encrypted rooms, messages, files and calls between the people you invite. It is published by ForgeSworn ("we", "us") under the MIT licence. These terms cover the software and this website.

If we change these terms, we will say so on the site. These terms do not take away any rights you have by law as a consumer.

2. What we run, and what we do not

We publish the software. The public website provides:

  • the web app, this website and the downloads as static files;
  • the update information the desktop app checks for.

Since 1 November 2026 we also run, for anyone using the app:

  • a public call relay (TURN), with a login service that needs no account, which the apps use by default when a call cannot connect directly;
  • a Nostr relay, relay.trotters.cc, which is the first relay the apps use by default and which anybody can read from and write to.

What each sees and keeps is in the privacy notice, sections 4.5 and 7. Until 22 October 2026 we also ran a file store, a message-drop service and meeting codes. Those are closed, and our call relay was closed from 22 October to 1 November 2026. What closed and when is set out in the closure record.

A separate authenticated private relay remains for an arranged personal call. Private deployments have separate operator and access arrangements, described in the privacy notice, section 4.5.

3. Who runs your rooms

  • Rooms travel over Nostr relays. The app suggests four by default: relay.trotters.cc, which we run, and three public relays run by other people. A room's creator can choose others.
  • Calls use the STUN and TURN settings chosen by the device, room or installed build. From desktop 0.1.124 and Android 0.6.132, and in the web app, the defaults are Google's and Cloudflare's STUN servers and our call relay. You can set your own STUN server, and a relay supplied by an independent provider or one you run yourself, which replace ours. From desktop 0.1.120 and Android 0.6.130 you can also run a call relay on your own computer or phone; it is off until you turn it on, you run it, not us, and only you can stop it.
  • In the web app and the desktop app, files you send go by default to a public file server run by somebody else (section 4), or to a server you choose.
  • A room's link is its access control. Whoever creates a room decides who to send it to.
  • Operators are responsible for what they run under the laws and agreements that apply to their deployment. Using a bundled app, running one login or forwarding encrypted packets does not by itself settle its legal classification. Transport infrastructure and control of the underlying communications service need separate analysis.

4. What others can see

  • Rooms are end-to-end encrypted. The traffic key stays in the room's own link and the devices in it. Nothing we run for KithMoot users holds a room's key.
  • Relays see event kinds, device public keys, opaque room selectors, timing and the size of what is sent.
  • Unless you choose another server, the web app and the desktop app send files to blossom.yakihonne.com, a public server run by Yakihonne LLC in the United States, with its own terms. Each file is encrypted on your device first. We do not run that server and cannot remove anything from it.
  • Other defaults that contact third parties are listed in the privacy notice.

5. Your keys

  • Your Nostr key, if you use one, is yours. KithMoot never sends your private key to us.
  • Without a Nostr key, the app makes a per-device, per-room key on your device.
  • We cannot recover a lost key, room link or device pairing for you.
