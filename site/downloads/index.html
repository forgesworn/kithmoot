Apple Silicon

For M1, M2, M3, M4 and later Apple Silicon Macs. Requires macOS 13 or later. No Intel Mac build yet.

Signed and notarised. Apple has notarised this Mac preview.

Download for Mac

Version 0.1.62 · 132 MiB · SHA-256 checksums

Install on macOS
  1. Download and open the ZIP.
  2. Quit any running copy of KithMoot, then move KithMoot.app into your Applications folder.
  3. Open KithMoot and approve the usual first-launch prompt. You may need to grant screen-recording permission again when upgrading from an older preview.

Signed Mac releases download quietly and wait until you approve a restart; calls, shares, uploads and unsent work block that restart. Your desktop login is separate from your browser login.

Windows · portable preview

Windows 10 or 11 x64

Extract the whole ZIP and open KithMoot.exe. Keep the folder together. From 0.1.48 KithMoot updates itself, checking each update against a signed release manifest before installing it; keep the folder somewhere you can write to. Your local profile remains under your Windows account.

Unsigned preview. Windows may show an unknown-publisher warning or refuse it under local security policy. A clean-machine Windows call and screen-share check remains outstanding.

Android · 0.6.69

Your chats and rooms on your phone.

For Android 13 or later. New messages arrive as notifications even with KithMoot closed, with a Reply you can send from the notification. Calls ring like a phone call, and your rooms follow your account from your other devices.

Download Android 0.6.69

Production-key signed · Checksum and signing details

Install or update
  1. Open the downloaded APK and choose Install, or Update over an earlier version. Do not uninstall first: updating keeps your account and rooms. From 0.6.54 on, KithMoot offers new versions itself.
  2. Sign in with the same Nostr account you use elsewhere.

A direct download, not a Play Store listing. Android 8 to 12 cannot install it; the older 0.5.12 preview still works there, without the newer sync and call improvements.

Debian, Ubuntu and the rest

Intel or AMD computer? Choose x64. An ARM64 computer? Choose ARM64. Run uname -m if unsure: x86_64 means x64; aarch64 means ARM64.

Install the .deb package
  1. Open the downloaded package with your software installer, or in a terminal in your Downloads folder run sudo apt install ./kithmoot_0.1.62_amd64.deb (or the arm64 file).
  2. Open KithMoot from your applications menu.

Installing it adds KithMoot's signed software source, so new versions arrive with your usual system updates. If KithMoot is open when one arrives, it offers a restart, and waits while you are on a call. Your profile in ~/.config/KithMoot is never touched: not by updates, and not by removing the package. Moving over from the tar.gz install keeps it too.

Works on Debian 12 and later and Ubuntu 22.04 and later, and the distributions built on them.

Add the software source yourself

To install through apt without downloading the package first:

sudo wget -qO /etc/apt/sources.list.d/kithmoot.sources https://github.com/forgesworn/kithmoot/releases/download/apt/kithmoot.sources
sudo apt update && sudo apt install kithmoot

The source file carries the key the repository is signed with, the KithMoot archive key, fingerprint D6D7 B42A 6909 85CC 3DDC C676 F546 951E DCB5 E0DC. It is served from the project's GitHub releases.

Install from the tar.gz
  1. Extract the downloaded tar.gz archive.
  2. Open a terminal in the extracted KithMoot folder.
  3. Quit KithMoot if it is running, then run python3 install.py.
  4. Open KithMoot from your applications menu.

The installer runs as your own user, without sudo. It installs under your user data directory and adds a menu entry. From 0.1.48 KithMoot updates itself, checking each update against a signed release manifest and asking before it restarts. Your profile is preserved.

Requires Python 3, a current glibc-based desktop with GTK 3, NSS and ALSA libraries, and permission to use unprivileged user namespaces. Some distributions restrict these; ask your administrator if the sandbox prevents startup.

Share Area works on X11 with the movable crop frame, and on Wayland through a preview: choose a screen, drag a box around what to share, and only that box is sent. Linux system audio is not captured. The Wayland screen chooser and physical X11, GNOME and KDE checks remain outstanding.

    When will I receive notifications?

    Enable notifications in KithMoot and allow them in your operating system. Keep the app window open or minimised. Quitting stops delivery; closing the last Linux window quits the app. Quiet rooms only receive notifications while that room is open.

    Notifications name the sender and room. Message text is opt-in. Linux icon badges depend on your launcher; some desktops need an extension. The Zen bell is app audio: mute it using its own switch when you want silence, including during an OS Focus mode.

    What still needs testing?

    The sharing area still needs physical checks for capture, resizing and drawing alignment. Linux X11 has not yet had a physical desktop run, and on Wayland nobody has yet checked that the system screen chooser appears once and that the far end sees the picture. Linux system audio is not captured. Physical iPhone and Mac checks are pending too.

    How do I check my download?

    Download SHA256SUMS.txt into the same folder as your archive. On macOS run shasum -a 256 KithMoot-0.1.62-mac-arm64.zip; on Linux run sha256sum kithmoot_0.1.62_*.deb or sha256sum KithMoot-0.1.62-linux-*.tar.gz; on Windows run Get-FileHash KithMoot-0.1.62-windows-x64.zip -Algorithm SHA256. Compare the result with the matching filename in the checksums file. Every earlier version's checksum is listed under Need a particular version. The .deb's later updates are checked by apt against the signed repository.
