Model Workshop

Review footage and labels for our face masking and background removal models.

Files stay in this browser until you explicitly export them. This local tool has no upload or training endpoint. Public model training needs a separate, explicit source-rights review.

3. Save the review and prepare training

A saved review contains pictures and permission notes. Keep it out of Git. Training export requires approved sources and independently grouped training, validation and test frames.

On the M4, use a Python environment with the vision dependencies and run from the repository’s vision/ directory. Choose fresh output names.

python -m kithmoot_vision.workshop ~/Downloads/kithmoot-workshop-training-*.json --output data/reviewed-001
python -m kithmoot_vision.train data/reviewed-001/manifest.jsonl runs/reviewed-001 --device mps --steps 1000
python -m kithmoot_vision.evaluate runs/reviewed-001/experimental.pt data/reviewed-001/manifest.jsonl
python -m kithmoot_vision.export runs/reviewed-001/experimental.pt runs/reviewed-001/experimental.kvm

These commands produce experimental weights. Compare them in Camera Lab; footage, licensing declarations and training loss do not qualify a model for calls.
