# KithMoot identity, September 2026

The four-arm vortex and the KithMoot wordmark, from the branding board of
29 September 2026. These SVGs are the vector masters; `SVG-PACK.md` says what
each file is for and `KithMoot-brand-developer-guide.md` gives the palette,
type and usage rules.

`npm run brand:site` copies the lockups into `site/img/brand/` and renders the
website's favicon, touch icon and social card. `npm run brand:build` renders the
app's PWA icons, the desktop tiles in `desktop/icons/` and `KithMoot.ico`
(ImageMagick), and the Android launcher foreground in a sibling
`kithmoot-android` checkout. The 9 September artwork (`../2026-09-09`) is kept
for the record and no longer used.
