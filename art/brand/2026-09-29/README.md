# KithMoot identity, September 2026

The four-arm vortex and the KithMoot wordmark, from the branding board of
29 September 2026. These SVGs are the vector masters; `SVG-PACK.md` says what
each file is for and `KithMoot-brand-developer-guide.md` gives the palette,
type and usage rules.

The website uses them now: `npm run brand:site` copies the lockups into
`site/img/brand/` and renders the site's favicon, touch icon and social card.
The app, desktop and Android icons still come from the 9 September artwork
(`../2026-09-09`) through `npm run brand:build`, until they are moved over too.
