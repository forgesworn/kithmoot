# Ordinary entry choices and layout custody

`validateOrdinaryEntryLayoutSnapshot` completes additional writer formats needed
by the dormant protected ordinary persistence branch. It returns frozen counts,
never identities, invited people, consent, channel names or applied layout values.
It does not run a loader, clock, signer, notification prompt, invitation, DOM
operation, pruning or network request. Raw and completed images share checks;
unsupported versions, account wrappers, malformed values and wrong owners hold.
Each recognised name/value receives the existing name/8 MiB UTF-8 bounds before
JSON parsing. This helper leaves other families for the complete classifier.

The last row deliberately separates stored bytes from current reader behaviour.
The actual divider fraction helper can produce 1.8 for a 200-pixel container;
using today's reader's strict (0,1) interval as the migration format would lose
that writer output. The rail's actual UI clamp uses 176–512 px, but its exported
setter takes any number and rounds it. Synthetic direct-writer tests exercise
ignored values and NaN/Infinity. They establish callable writer cuts, not that
real controls generated those parameters or that those values are safe to apply.

Fixtures import actual pure writers and record primary module hashes. Main's
knock/invited/key-getter functions and conversation set expression are exact
TypeScript AST captures with explicitly injected globals and Storage. They omit
surrounding controls, authentication, invitation, consent and rendering paths.
The invited empty-list case executes the actual setter and generic sweep with a
synthetic identifier. No remote deletion or composed app forget is performed.

Unit and native-browser tests cover exact bytes, single-write interruption,
opaque/empty/capped lists, unbound tab selection, ignored numeric choices,
wrong owners, malformed raw/completed rows and reload. The native harness uses
real Storage/WebCrypto/IDB, a no-op client fence and synthetic tab purpose/deadline.
It selects both dot and colon private namespaces. That is bounded custody
evidence, not actual all-client, tab-lifetime or production startup acceptance.
