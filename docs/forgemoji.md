# ForgeMoji in KithMoot

ForgeMoji is original everyday emoji artwork by TheCryptoDonkey, published in the separate [ForgeSworn repository](https://github.com/forgesworn/forgemoji). KithMoot bundles a reviewed snapshot locally. The picker starts with familiar faces, hearts, hands and other recognisable Unicode meanings, including selectable human skin tones. Character stickers and the Nostr member pack have their own collection. Existing character shortcodes still render.

Messages and reactions keep their standard Unicode sequences, including the selected skin modifier. Rendering the artwork does not change copied text. Unfamiliar emoji clusters, text presentation and links remain intact. Other clients can display the same Unicode using their own renderer. The orange donkey uses the standard donkey meaning with original artwork based on TheCryptoDonkey's character.

The basic collection also includes the public 600 sacred stone, a black Little Leap jumping spider and the Bitcoin currency symbol (₿). ForgeSworn has a separate collection using the existing ForgeSworn, Kindred, KithMoot, MySignet and Vitark brand masters. These logos have explicit `:fs_*:` shortcodes because they have no Unicode equivalent; only bundled, known codes are accepted as reactions. Copying a brand graphic preserves its shortcode. The brand masters are rasterised locally with their established shapes and colours.

No graphics provider is contacted when browsing, searching or rendering the pack. Fresh web installations precache all 163 lossless WebP derivatives from their own origin, rather than the original PNGs. Original PNGs remain deployed as exact fallbacks and native inputs, and existing installations migrate already-precached copies before old precache entries can be removed. Unicode and shortcode text remains selectable beneath the local image. Desktop and Android continue to include the original PNGs. The local hand-colour preference applies to familiar picker choices and quick reactions. The 600 pack retains its explicit picker-only Nostr unlock; all 16 responsive WebP variants for its four used 1024px sources are precached.

The GIF collection includes the coffee goblin and three Blender performances of Donkey: a snorting laugh, an embarrassed facepalm and a Bitcoin coin toss and catch. Donkey retains the orange coat, black mane and tail, cream muzzle and dark hooves of TheCryptoDonkey's familiar emoji. Each animation has a matching still for reduced motion and can also be sent as a sticker. All four animations use the same bundled references as the other stickers, without artwork uploads or a graphics provider. An older app that has not bundled an animation displays its text fallback.

To update a reviewed snapshot, run `node scripts/sync-forgemoji.mjs --source /absolute/forgemoji --android /absolute/native-checkout`. Both repositories must be chosen explicitly. The script verifies every PNG against the source manifest's byte size and SHA-256, then records the source Git revision, licence and artwork model in the bundled manifest. Afterwards run `npm run artwork:generate` with the libwebp tools and FFprobe documented in [Original chat artwork](original-chat-art.md), then `npm run artwork:check`. Commit the generated definitions, exact packaged PNGs, all 163 WebP derivatives and `artwork/derivatives-v1.json` together. Routine checks need no image tools and never regenerate assets.
