# Desktop preview 0.1.11 — 20 September 2026

KithMoot now includes a signed Mac automatic-update path. Packaged Apple Silicon
builds check the ForgeSworn static release feed after startup and every ten
minutes. A downloaded update appears in the existing update notice; KithMoot
only restarts when the person explicitly chooses to update. The existing checks
for calls, drafts, uploads and pending room actions run before restart.

The updater is disabled in development and on Linux. Checks cannot overlap, UI
errors do not disclose raw network or filesystem details, and the main process
refuses installation while a call is active. Squirrel.Mac verifies the new app
against the running app's Developer ID signature before replacement.

## Verification

The coordinator tests cover platform gating, scheduling, overlapping checks,
download progress, terminal ready state, generic errors, cleanup and one-shot
installation. Feed tests check the exact archive hash and byte size. The full
unit suite, typecheck, focused Chromium update journeys and development Electron
smoke passed. The signed packaged app also passed its updater-aware native smoke.

This is the first updater-capable release and must be installed manually. A real
0.1.11 to 0.1.12 replacement is the remaining physical acceptance gate; a
successful feed check in 0.1.11 cannot prove replacement until a newer signed
release exists. Linux archives have not been run on physical Linux desktops.
