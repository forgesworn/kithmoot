# Desktop preview 0.1.12 — 20 September 2026

The always-on-top sharing frame could leave the live KithMoot call window inaccessible behind the frame or the app being shared. The frame now has a **KithMoot** control that restores and raises the call window. The main window keeps the elevated level only while it has focus; when focus moves away, it returns to its normal level and the sharing frame retakes the front.

The frame is detached from macOS child-window stacking so the explicit switch can change their order. It remains always-on-top at the screen-saver level and visible across workspaces and fullscreen spaces. Existing crop insets, click-through drawing surface, movement, resizing and capture bounds are unchanged.
