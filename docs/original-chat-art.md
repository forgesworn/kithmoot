# Original chat artwork

KithMoot's everyday emoji picker starts with [ForgeMoji](forgemoji.md): familiar faces, hearts, thumbs up/down and other recognisable Unicode meanings, including selectable human skin tones. Messages and reactions keep their standard Unicode sequences. The character artwork has its own collection rather than replacing everyday emoji.

The character collection includes 24 original reaction stickers, three Donkey stills and four acted GIFs. The initial sticker artwork was generated with the explicitly selected `gpt-image-2.5-sunburst` model; prompts and source sprite sheets are kept in `app/artwork-prompts/` and `app/src/assets/kithmoot-original/`. The Donkey stills come from the Blender performances. The separate 600 pack retains its explicit Nostr member unlock and picker-only gate. Existing Unicode and character shortcode reactions remain readable; flags are omitted from the picker.

The coffee animation is an original editable 3D interpretation of the sticker, modelled and animated in Blender on the M4. Its six-second performance includes a sip, contented pause, caffeine shock, coffee spill and guilty glance. The face, hands, arms and mug move separately. The committed GIF is transparent, 512 pixels square, 144 frames at 24 fps and under six megabytes. Its static preview also comes from the Blender master. Source scripts and regeneration instructions are in `artwork/animation/coffee/`. The other 23 flat rotating/bouncing GIFs are excluded from the picker; their packaged files remain available for existing messages.

Donkey has three performances: a snorting laugh, an embarrassed facepalm and a Bitcoin coin toss and catch. The orange quadruped, tall ears, black mane and tail, cream muzzle and dark hooves follow TheCryptoDonkey's familiar Donkey artwork. Each transparent 512-pixel GIF has a matching still for sticker use and reduced motion. Editable source and export instructions live in `artwork/animation/donkey/`. The catalogue marks reviewed animations explicitly, so adding an entry never enables an old flat GIF by accident.

The composer uses one tray with Emoji, Stickers and GIFs tabs. Emoji insertion keeps the tray open for repeated choices; reaction choices close it. Familiar, Recents, ForgeSworn, Characters and More emoji collections remain accessible on narrow screens and in landscape. Hand colour is remembered locally. Phone browsing starts with the keyboard dismissed, and search opens it explicitly. Media thumbnails open a larger preview; Add stages a bundled catalogue reference, followed by the separate Send action. Built-in artwork needs no upload or storage consent. Search and artwork browsing use bundled files without a third-party catalogue request.

Browsing and searching the local emoji, GIF and sticker collections makes no third-party graphics requests. The PWA precaches artwork from its own origin; desktop and Android package it. Native GIF previews use local assets, respect disabled system animation and stop with the view lifecycle. Web previews use the Blender static preview when reduced motion is requested. Choosing a personal file uses the existing encrypted attachment flow and storage consent. Built-in stickers and GIFs send only their encrypted catalogue references; recipients display their own bundled artwork. Browsing the pack does not grant storage consent, and no third-party credit or URL is inserted into the draft.

To regenerate the 24 character stickers and the complete catalogue metadata, run `node scripts/build-original-chat-art.mjs` with FFmpeg installed. This preserves and verifies the reviewed coffee and Donkey animations and previews, and never recreates the old flat GIFs. To supply a reviewed coffee Blender export instead, add `--coffee-export /absolute/export-folder`; the folder must contain `coffee.gif` and `coffee-preview.png`. Donkey export hashes and byte sizes are pinned in `artwork/animation/donkey/reviewed-assets.json`. The script verifies pinned hashes, 512-pixel dimensions and GIF size before changing assets. A new animation must be reviewed before its pinned hashes are updated. `node scripts/build-original-chat-art.mjs --check` verifies packaged artwork and metadata without modifying assets.

To update the explicitly selected native checkout, run `node scripts/sync-original-chat-art.mjs --android /absolute/native-checkout`. The generated manifests pin file sizes and hashes; web selection rejects substituted URLs or bytes. Native selection accepts only the compiled catalogue and exact APK asset lengths. ForgeMoji has its own explicit snapshot synchronisation command documented separately.

The collection is a finite local pack. People can also attach their own images and GIFs through the existing file picker.
