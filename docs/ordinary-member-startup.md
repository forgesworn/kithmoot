# Guarded member startup

`OrdinaryMemberStartup` owns one selected persistent member from historical
recovery through fresh ordinary role construction. Its caller supplies actual
browser/tab owners, an immutable invitation selection and, for an account, a
genuine currently selected SDK session. SDK discovery and restoration are
still the caller's responsibility; this controller never silently logs in.

Before any recovery write, whole-origin inspection refuses a provider-started
operation without a result and any prepared operation belonging to another tab.
The selected prepared operation uses the fixed one-use recovery factory.
Retained results use the existing historical C and S writers. A second native
inspection must recognise ordinary storage before current role construction.

Each owner then opens existing completed custody through `openExisting`. That
read-only method aborts initial database creation, refuses absent or pending
rows and incomplete migration, authenticates complete operation classification
and the exact native purpose/expiry/generation, and installs only private
generation/classification caches. Database version changes revoke the owner.
It returns no image, key, view, callback token or role. It does not use `prepare`
to turn deleted custody into a new installation.

Fresh ordinary foreground construction, persistent bootstrap construction and
selected material loading independently repeat native composition and current
identity/deadline checks. Historical S does not supply a usable credential.
Loaded material is wiped before the controller escapes. Only the existing
scoped `OrdinaryOwnedMemberSession` can subsequently be constructed, once;
no raw library Session or protocol executor escapes. The existing member
factory supports the default open policy; other roles and policies remain open.

The exact outer startup/member promises are retained by both owner lifetimes
before their first continuation. Revocation disarms the bootstrap and signer,
and schedules cleanup outside the refusing promise. Close joins native reads,
providers, the unreturned member and owned secret cleanup. The SDK signer is
borrowed: its original owner must close it after this controller has joined.

Native tests use actual encrypted IndexedDB records and real signed protocol
events. Their synthetic authority verifies the actual epoch request and seals
its grant to the request's credential. Test fault observers do not replace
production native checks. They do not prove real relay/device acceptance.

Full application entry mounting, SDK restoration before E, all other consumers,
old-client/service-worker fencing, independent rollback continuity, current MLS
authority, registry installation, deployment and physical acceptance remain open.
